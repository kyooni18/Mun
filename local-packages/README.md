# Local package output

This directory is generated by `pnpm pack:local`.

For day-to-day development, prefer source links:

```bash
pnpm dev:link ../my-app
pnpm dev:watch
```

When you specifically need tarballs, run:

```bash
pnpm pack:local
pnpm local:install ../my-app
```

`local:install` writes direct `file:` dependencies plus pnpm 11 workspace overrides for all
internal `@mun/*` packages, so unpublished transitive dependencies do not
fall through to the public npm registry.
